# tgs-bot

Telegram-бот для работы с анимированными стикерами. Делает из стикера или
премиум-эмодзи широкий видеобаннер и собирает именные эмодзи-паки: подставляет
ник или логотип пользователя в готовые анимации и публикует набор в Telegram.

## Возможности

**Баннеры.** Принимает стикер, премиум-эмодзи, файл `.tgs` или ссылку на пак и
рендерит MP4 или GIF (по умолчанию 1920×530, 60 fps). Фон: цвет, картинка или
видео. Эмодзи можно перекрасить в любой цвет с сохранением теней и бликов,
поверх наложить свой водяной знак. Настройки сохраняются в пресеты, ими можно
делиться по ID.

**Эмодзи-паки.** Пользователь выбирает тайлы в редакторе (Telegram Mini App),
задаёт ник или загружает SVG-логотип, шрифт и цвета, при необходимости двигает,
масштабирует и поворачивает надпись на отдельных тайлах. Бот переписывает
Lottie-разметку каждого тайла и создаёт набор custom emoji или стикеров
через Bot API.

**Монетизация.** Внутренний баланс, оплата через СБП (Platega) и CryptoBot с
автоматическим зачислением, ручное подтверждение переводов админом.
Реферальная программа с капчей против накруток, промокоды.

**Админка.** Статистика, цены, балансы пользователей, рассылки с медиа и
кнопками, редактор всех текстов и кнопок бота без деплоя, обложки экранов,
канал с отчётами о покупках.

## Как это устроено

- **Рендер.** Основной движок — [rlottie](https://github.com/Samsung/rlottie)
  (тот же, что в клиентах Telegram). Если премиум-эмодзи рендерится пустым
  (у rlottie есть такой баг на части файлов), бот повторяет попытку через
  python-lottie, а затем через препроцессор, исправляющий монохромную заливку.
- **Потоковый энкодинг.** Кадры композитятся и уходят в stdin ffmpeg по одному,
  без накопления всей последовательности в памяти: на 1920×530 полный буфер
  кадров не помещался в память небольшого VPS.
- **Подстановка текста.** Глифы выбранного шрифта превращаются в Lottie-шейпы
  через fontTools и встают на место плейсхолдера внутри исходной группы, так
  что наследуют её анимацию, трансформы и заливку. SVG-логотипы конвертируются
  в шейпы тем же способом.
- **Mini App.** Редактор (`webapp/`) рендерит превью прямо в браузере, а сборку
  запускает через API бота. Запросы авторизуются проверкой HMAC-подписи
  `initData` от Telegram.

## Стек

Python 3.12, aiogram 3, aiohttp, aiosqlite, NumPy, Pillow, rlottie-python,
python-lottie, fontTools, svgpathtools, ffmpeg, gifski, Docker.

## Запуск

```bash
cp .env.example .env    # заполнить BOT_TOKEN и ADMIN_IDS
docker compose up -d --build
docker compose logs -f bot
```

Контейнер работает от пользователя с UID 10001, поэтому каталогу с данными
нужны права на запись:

```bash
mkdir -p data && sudo chown -R 10001:10001 data
```

Редактор паков открывается только по HTTPS. Сервер мини-аппа слушает
`127.0.0.1:8080`; перед ним нужен reverse proxy с TLS (nginx, Caddy,
cloudflared), а публичный адрес указывается в `WEBAPP_URL`.

### Без Docker

Нужны ffmpeg, libcairo2 и, по желанию, gifski (без него GIF кодируется через
Pillow).

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

## Настройки

Все параметры задаются в `.env` (полный список с комментариями лежит в
`.env.example`). Основные:

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_IDS` | ID администраторов через запятую |
| `WEBAPP_URL` | публичный HTTPS-адрес редактора паков |
| `PLATEGA_MERCHANT_ID`, `PLATEGA_TOKEN` | оплата по СБП |
| `CRYPTOBOT_TOKEN` | оплата криптовалютой |
| `SUPPORT_USERNAME`, `PRIVACY_URL`, `TERMS_URL` | контакты и документы на экране «Информация» |
| `OUTPUT_WIDTH`, `OUTPUT_HEIGHT`, `OUTPUT_FPS` | параметры баннера по умолчанию |

Если ключи провайдера не заполнены, при выборе этого способа оплаты бот
сообщает, что он не настроен. Цены из `.env` используются только до первого
изменения в админке, дальше они хранятся в базе.

## Структура

```
bot.py                точка входа: сборка зависимостей, роутеры, фоновые задачи
config.py             конфигурация из окружения
db.py                 основная SQLite-база: пользователи, баланс, платежи
states.py             FSM-состояния и пользовательские задания на рендер
handlers/             обработчики: меню, рендер, паки, кошелёк, админка
keyboards/            inline-клавиатуры и callback-данные
content/registry.py   тексты бота по умолчанию
services/
  pipeline.py         потоковый рендер баннера
  tgs_renderer.py     рендер TGS с фолбэками
  pack_builder.py     сборка и публикация паков
  swex/               подстановка текста и логотипа в Lottie
  webapp_server.py    HTTP API мини-аппа
  payments/           Platega, CryptoBot, отчёты о покупках
webapp/               фронтенд редактора паков
master_pack/          144 исходных тайла эмодзи-пака
emoji_stickers_swex/  дополнительные тайлы
tools/                офлайн-скрипты подготовки ассетов
```

Скрипты в `tools/` нужны только при добавлении новых тайлов. Они размечают
плейсхолдеры в исходных стикерах и генерируют `master_pack_positions.json` с
координатами бейджей. Без этого файла позиция логотипа вычисляется
автоматически.
